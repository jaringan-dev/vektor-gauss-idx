When you hear from the system

  • After each EOD run (about 19:30): a status message, delivered silently when everything is fine.
  • After each backfill night (early morning): progress, silent when fine.
  • Every morning at 08:00 (once the morning task is registered): a status message with a sound. It is independent of the EOD script, so it also reports a missed EOD.
  • Any problem is delivered with a notification sound.
  • If the whole PC is off nothing can be sent. Add an outside check (healthchecks.io) so a missing message reaches you another way; see the README, "Uptime monitoring".
